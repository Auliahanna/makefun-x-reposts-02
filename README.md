Entry for make.fun's X reposts bounty: POSTS.json lists public X posts, each quoting or replying to a different recent @makefunai post, and main.ts copies that list to the output directory for scoring by reposts, quotes, and likes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
